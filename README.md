Travel Expense Calculator

Project Description

The Travel Expense Calculator is a Java program that calculates the estimated cost of a trip. It collects information about the traveler, destination, trip duration, hotel expenses, food expenses, transportation, and activities.

The program uses this information to calculate the total trip cost, average daily cost, and estimated total rounded to the nearest whole dollar.

Features

- Collects the traveler's name and destination.
- Takes the number of travel days as input.
- Calculates total hotel expenses.
- Calculates total food expenses.
- Includes transportation and activity costs.
- Calculates the grand total of the trip.
- Calculates the average cost per day.
- Estimates the total cost rounded to the nearest whole dollar.
- Displays a summary of the trip and its expenses.

How It Works

1. Input

The program uses Java's "Scanner" class to collect information from the user, including the traveler's name, destination, trip duration, and expenses.

2. Expense Calculations

The program multiplies the daily hotel and food costs by the number of days to calculate their respective totals.

3. Total Trip Cost

The program adds the hotel, food, transportation, and activity expenses to calculate the grand total. It uses compound assignment operators ("+=") to add each expense.

4. Average Daily Cost

The program divides the total trip cost by the number of travel days to calculate the average cost per day.

5. Rounding

The program estimates the total cost to the nearest whole dollar using a rounding calculation.

6. Output

The program displays a formatted travel summary containing the traveler's information, expense breakdown, total trip cost, average daily cost, and rounded total.

Technologies Used

- Java
- Scanner class for user input
- Variables and data types
- Arithmetic operators
- Compound assignment operators
- Type casting
- Console output

How to Run

1. Download the "HelloWorld.java" file.
2. Make sure Java is installed on your computer.
3. Open the file in a Java development environment.
4. Run the program.
5. Enter the requested travel information when prompted.
